Entry for the [Everyday Things, Two Lines, Longer Run](https://make.fun/bounty/u-suga-everyday-things-two-lines-longer-run-f8734479) bounty on make.fun.

`main.ts` writes a fresh, original two-line explanation of a toaster to
`/output/entry.txt`: line 1 explains it to a 10-year-old in a single vivid
sentence built on an analogy (a tiny elevator riding bread down into a hot
cave), and line 2 says in one sentence what that analogy maps and what it
leaves out. The program is deterministic and checks the gate itself
(UTF-8 text, 1–400 characters, exactly two non-empty lines) before writing.

Run it from anywhere:

```sh
node main.ts
```

It writes to `$MAKEFUN_OUTPUT_DIR/entry.txt` when set, otherwise to
`output/entry.txt` next to the program.
